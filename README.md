# 📚 Personal Study Dashboard

A Streamlit web app to track your study sessions, manage goals, and analyze your progress.

## Features

- ✅ Log study sessions with custom subjects
- ✅ Track total hours, sessions, and most studied subject
- ✅ Weekly goal tracker with progress visualization
- ✅ Charts showing hours by subject and over time
- ✅ Filter sessions by subject
- ✅ Download study log as CSV

## Tech Stack

- **Python** - Programming language
- **Streamlit** - Web framework
- **Pandas** - Data manipulation
- **NumPy** - Statistics
